# Общее описание решения

Скрипты на Python для вычисления площади и периметра геометрических фигур: круг (`circle.py`), прямоугольник (`rectangle.py`), квадрат (`square.py`) и треугольник (`triangle.py`).

# Описание каждой функции с примерами вызова

### Файл `circle.py` (Круг)

Функция `area(r)`
* Описание: функция возвращает площадь круга с радиусом r.
* Параметры: 
	* `r (int)`: радиус круга в виде целого числа
* Возвращаемое значение:
	* `area_multiply (float)`: произведение числа Пи и квадрата радиуса (площадь круга)
* Примеры вызова:
```python
>>> area(5)
78.53981633974483
>>> area(3)
28.274333882308138
```

Функция `perimeter(r)`
* Описание: возвращает периметр круга с радиусом r.
* Параметры: 
	* `r (int)`: радиус круга в виде целого числа
* Возвращаемое значение:
	* `perimeter_multiply (float)`: удвоенное произведение числа Пи и радиуса (периметр круга)
* Примеры вызова:
```python
>>> perimeter(3)
18.84955592153876
>>> perimeter(7)
43.982297150257104
```


### Файл `rectangle.py` (Прямоугольник)

Функция `area(a, b)`
* Описание: возвращает площадь прямоугольника со сторонами a и b.
* Параметры: 
	* `a (int)`: первая сторона прямоугольника в виде целого числа
	* `b (int)`: вторая сторона прямоугольника в виде целого числа
* Возвращаемое значение:
	* `area_multiply (int)`: произведение сторон (площадь прямоугольника)
* Примеры вызова:
```python
>>> area(2, 5)
10
>>> area(3, 5)
15
```

Функция `perimeter(a, b)`
* Описание: возвращает периметр прямоугольника со сторонами a и b.
* Параметры: 
	* `a (int)`: первая сторона прямоугольника в виде целого числа
	* `b (int)` вторая сторона прямоугольника в виде целого числа
* Возвращаемое значение:
	* `perimeter_sum (int)`: сумма удвоенных сторон (периметр прямоугольника)
* Примеры вызова:
```python
>>> perimeter(1, 5)
12
>>> perimeter(2, 3)
10
```


### Файл `square.py` (Квадрат)

Функция `area(a)`
* Описание: возвращает площадь квадрата со стороной a.
* Параметры: 
	* `a (int)`: сторона квадрата в виде целого числа
* Возвращаемое значение:
	* `area_square (int)`: квадрат стороны (площадь квадрата)
* Примеры вызова:
```python
>>> area(5)
25
>>> area(7)
49
```

Функция `perimeter(a)`
* Описание: возвращает периметр квадрата со стороной a.
* Параметры: 
	* `a (int)`: сторона квадрата в виде целого числа
* Возвращаемое значение:
	* `perimeter_multiply (int)`: учетверенная длина стороны (периметр квадрата)
* Примеры вызова:
```python
>>> perimeter(3)
12
>>> perimeter(5)
20
```


### Файл `triangle.py` (Треугольник)

Функция `area(a, h)`
* Описание: возвращает площадь треугольника, выраженная через сторону a и проведенной к ней высоте h.
* Параметры: 
	* `a (int)`: сторона треугольника в виде целого числа
	* `h (int)`: высота треугольника в виде целого числа, проведенная к стороне треугольника
* Возвращаемое значение:
	* `area_multiply (float)`: произведение стороны и проведенной к ней высоты, деленная пополам (площадь треугольника)
* Примеры вызова:
```python
>>> area(7, 8)
28.0
>>> area(10, 4)
20.0
```

Функция `perimeter(a, b, c)`
* Описание: Возвращает периметр треугольника со сторонами a, b и c
* Параметры: 
	* `a (int)`: первая сторона треугольника в виде целого числа
	* `b (int)`: вторая сторона треугольника в виде целого числа
	* `c (int)`: третья сторона треугольника в виде целого числа
* Возвращаемое значение:
	* `perimeter_sum (int)`: сумма трех сторон треугольника (периметр треугольника)
* Примеры вызова:
```python
>>> perimeter(3, 4, 5)
12
>>> perimeter(3, 7, 8)
18
```
